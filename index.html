Responsive Strategy

When to use container queries versus viewport media queries.

Container queries are used on cards (container-type: inline-size). They allow a component to adapt based on the width of its parent container rather than the entire viewport. This is ideal for reusable components that may appear in sidebars, modals, or multi-column layouts.

Viewport media queries (via the respond-to mixin) are used for page-level layout decisions such as grid column counts and container max-widths. These affect the overall structure of the page and are more appropriate when the layout change should respond to the device size.

Rule of thumb: use container queries for component internals; use media queries for page layout.
